## Resumen

Este proyecto muestra el clima actual y el pronóstico de varias ciudades en una interfaz clara y rápida.

## Arquitectura

Usé Astro para la base del sitio y componentes cliente solo donde era necesario. Los datos se obtienen desde OpenWeather API y se visualizan con gráficos simples.

## Aprendizajes

Fue un buen ejercicio para manejar estados de carga, errores de API y cachear respuestas para mejorar la experiencia.
