## Resumen

OpenBoard es una pizarra online para sesiones de ideación. Los usuarios pueden crear notas, mover elementos y ver cambios en tiempo real.

## Arquitectura

El frontend usa Vue y Canvas API para la interacción visual. La sincronización en tiempo real se implementó con WebSockets en Node.js.

## Aprendizajes

Este proyecto me ayudó a profundizar en eventos en tiempo real, renderizado en canvas y resolución de conflictos simples entre usuarios.
