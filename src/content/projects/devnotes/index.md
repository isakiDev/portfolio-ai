## Resumen

DevNotes nació como una herramienta personal para guardar notas técnicas, comandos y snippets reutilizables.

## Arquitectura

La app funciona con un enfoque local-first usando IndexedDB para persistencia. La interfaz está construida con React y Vite para mantener un desarrollo rápido.

## Aprendizajes

Aprendí a diseñar una experiencia de búsqueda instantánea y a estructurar contenido Markdown para que sea fácil de editar y consultar.
